Website Language Audit

Review static text, localized SEO fields and image descriptions on published Odoo 19 website pages.

  • Choose one website and one enabled non-default language.
  • Open advisory findings in Odoo's native page editor.
  • Keep page bodies and translations in Odoo; the audit stores metadata and hashes only.

Identical copy can be intentional. Dynamic QWeb content and rendered JavaScript are outside this audit.
